# Sistema de diseño

Sistemas de diseño de Javier Echaide para documentos y presentaciones.

| Carpeta | Estado |
| --- | --- |
| `academico/` | Documentos de clase: avances de proyecto, prácticas y entregas. Definido. |
| `personal/` | Pendiente de definir. |

Cada carpeta usa el mismo formato que el lienzo de Claude: `tokens.json` con colores, tipografías, espaciados y trazos, `README.md` con las reglas de uso y `components/Cover/preview.html` con la portada del sistema.

Las presentaciones todavía no están definidas en ningún sistema.
