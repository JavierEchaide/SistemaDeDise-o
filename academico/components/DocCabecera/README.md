Cabecera de la primera página de un documento académico: etiqueta superior, título, subtítulo con regla de acento y tres campos (ASIGNATURA, ALUMNO, CURSO).

Los estilos son `doc-eyebrow`, `doc-title`, `doc-subtitle`, `doc-label` y `doc-body`; la regla es `stroke-accent`. El orden y el texto de cada campo están en la sección Docs.
